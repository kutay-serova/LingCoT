Help

LingCoT will offer to set up Autosave whenever you create or open a corpus. Click Yes, autosave and your changes will be written to disk automatically after each edit — no manual saves needed.

You can also configure save paths at any time by clicking Save in the header to open Project Files.

If your corpus is stored in a managed corpora/ folder, Export as .zip bundles the corpus, dictionary, and participants files into a single archive for sharing or backup.

Corpus: click Open in the header, or drag and drop a .jsonl corpus file onto the window.

Dictionary: after loading a corpus, a banner will appear if no dictionary is loaded. Click Load dictionary… in the banner, or use the Dictionary button in the header. LingCoT remembers which dictionary you last used with each corpus and shows it as a suggestion next time.

Replacing the dictionary: load a new dictionary at any time — your corpus is never affected. Useful for swapping between a general-purpose and a domain-specific dictionary.

Both file types use newline-delimited JSON (.jsonl) — one document per line for corpora, one entry per line for dictionaries.
