─────────────────────────────────────────────────────────────────────────────
Standards and Reference Data
─────────────────────────────────────────────────────────────────────────────

The tag sets below follow published linguistic standards. The tag names are the
standards' own; the descriptions and examples in the JSON files were written for
this project. Listed for attribution, not because a licence requires it.

Leipzig Glossing Rules
  Gloss abbreviations in source/resources/leipzig_glosses.json.
  Max Planck Institute for Evolutionary Anthropology and the University of
  Leipzig. https://www.eva.mpg.de/lingua/resources/glossing-rules.php

Universal Dependencies
  POS tags (source/resources/pos_tags.json) and dependency relations
  (source/resources/dep_relations.json). https://universaldependencies.org

ISO 639 language codes
  Code and alias table in source/resources/language_codes.json, alongside
  BCP-47 tags and the NLLB and Stanza code sets.
